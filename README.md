# Library-manger

This Python-based program allows users to manage a digital library and
perform automated text analysis on classic literature [cite: 1, 3, 4]. It
fetches raw text data from Project Gutenberg using an API, cleans the data
using Regular Expressions, and performs frequency analysis to identify the
most common words in a book [cite: 1, 3, 4].

Library Management: Add, remove, or update Gutenberg .txt URLs[cite: 1, 3, 4].
Automated Cleaning: Converts text to lowercase and removespunctuation for accurate analysis [cite: 1, 3, 4].
Stop Word Filtering: Excludes common "stop words" using an externalfile to focus on key themes [cite: 1, 3, 4].
Visual Insights: Displays word frequency using character-based barcharts [cite: 1, 3, 4].
Robust Error Handling: Gracefully manages network errors and invalidURLs [cite: 1, 3, 4].
